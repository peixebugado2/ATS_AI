CAREEROPS STUDIO

Quick Start

1. Extract the ZIP file.

2. If Python is not installed, install Python 3.11 or newer:
   https://www.python.org/downloads/

3. Run:

install.bat

Wait until the installation completes successfully.

4. Open the .env file and insert your API key.

5. Run:

run.bat

The application will open automatically in your browser.

Usage

1. Upload or confirm the source files:

   * Instructions
   * Experience Repository
   * Manager CV Template
   * Director CV Template

2. Paste the Job Description.

3. Click:

Generate Client-Ready CV

The system will:

* Select the appropriate CV path (Manager or Director)
* Match the most relevant achievements from the Experience Repository
* Optimize ATS alignment
* Generate a tailored CV
* Generate ATS validation
* Generate a cover letter (if selected)
* Export to PDF and DOCX

Notes

* The Experience Repository is the source of truth.
* The system should not invent achievements, metrics, companies, dates, certifications, budgets or KPIs.
* If an API error occurs, verify that the API key is valid and active.
